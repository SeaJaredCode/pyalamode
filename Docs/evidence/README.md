# Verification evidence

The Markdown files in this directory retain measurement reports and verification contracts.
Generated JSON records, compressed audit bundles, and `m14-publication/` logs are local-only and ignored by Git. Existing local copies can stay at these paths; they are not required to build or run Pyalamode.

Historical milestone documents may refer to those local records. They are not included in a fresh checkout. Repository test fixtures under `tests/fixtures/` remain versioned.
