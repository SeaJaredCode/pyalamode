## 2. Concrete public API and useful example

```toml
[tool.pyalamode]
schema = 1
builders = true
```

```python
from pyalamode import Vector, VectorBuilder, fun, vector_build

@fun
def positive(value: int) -> bool:
    return value > 0

@fun
def doubled(value: int) -> int:
    return value * 2

@fun
def assemble(first: Vector[int], second: Vector[int]) -> Vector[int]:
    def fill(out: VectorBuilder[int]) -> None:
        out.extend(first.filter(positive).map(doubled))
        out.append(-1)
        out.extend(second)
    return vector_build(fill)
```

For `first=Vector.of(-2,3,4)` and `second=Vector.of(8,9)`, ordinary accepted execution returns exact `Vector.of(6,8,-1,8,9)`. Both input Vectors retain their prior contents. This finite composition copies the admitted bulk elements into one private staging list and automatically publishes one immutable Vector. No public query or manually transferable construction handle exists.
