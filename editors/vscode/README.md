# Pyalamode local VS Code client

This local desktop extension uses the installed checker server for compatible Python and the experimental `.pya` edition. It adds no npm runtime dependency. Native VS Code 1.139.1 is the characterized local editor from M09; the new M14 client and host controls require separate execution evidence. Human repair usefulness is **UNMEASURED**.

Install Pyalamode into the supported CPython 3.13.1 virtual environment. In VS Code User settings set `pyalamode.pythonPath` to its absolute interpreter path, for example `/Volumes/Projects/pyalamode/.venv/bin/python`. Preserve the virtual environment path. Open one trusted local workspace containing existing `.py` or `.pya` files. The client starts that executable with `-I -m pyalamode.editor --stdio --root <workspace>`, without a shell; isolated startup excludes workspace import paths, user site and `PYTHON*` environment overrides. The installed environment must contain Pyalamode; relying on the workspace or `PYTHONPATH` to locate the tool is unsupported. Its Output channel records actual launch and server metadata. Missing configuration, unsupported targets and transport failures are visible unverified states.

The `.pya` language includes finite highlighting for `val`, collection displays, comments and strings. Select `edition = "pyalamode-v1-experimental"` in `[tool.pyalamode]` and place `# mode: fun` at the module header for whole-module participation. Highlighting does not grant admission. Diagnostics, hover, definitions and references use authored locations, including Unicode and CRLF, while the checker retains all inherited data, effect, capture and lifetime contracts.

For local development, run `code --extensionDevelopmentPath=/Volumes/Projects/pyalamode/editors/vscode /path/to/project`. For a finite installable package, run:

```sh
.venv/bin/python editors/vscode/package_vsix.py --output /tmp/pyalamode-local.vsix
code --install-extension /tmp/pyalamode-local.vsix
```

The installer command is an intentional local installation step. Automated verification always supplies temporary `--user-data-dir` and `--extensions-dir`; it never changes the normal user profile. No Marketplace publication is provided.

Use VS Code **Format Document** explicitly on an existing `.pya` file. The finite formatter normalizes `val` spacing, trailing horizontal whitespace and the final newline while preserving string/comment bytes, indentation and complete checked contracts. The provider captures the document version, obtains a current project snapshot and returns standard edits only if the buffer is still unchanged. Refused or stale requests return no edits. The extension never applies a workspace edit or formats a background diagnostic update; VS Code owns applying the edits requested by the user.
